# 아이스크림 물주 뽑기

점심 먹고 아이스크림 내기할 때 폰으로 한 명 뽑는 한 페이지 게임이에요.

- 캐릭터(이모지)를 고르고 이름을 넣으면 그 폰에 저장돼요 (localStorage).
- 이름을 탭하면 오늘 빠지는 사람으로 바뀌고, "오늘만 게스트"는 저장되지 않아요.
- 연출 6종: 폭탄 돌리기, 슬롯머신, 룰렛, 스포트라이트, 카드 뒤집기, 최후의 1인 (+ 랜덤).
- 누적 물주 랭킹이 쌓여요.

`index.html` 하나로 동작하고, GitHub Pages로 켜면 바로 폰에서 열 수 있어요.
`src/body.html`은 같은 내용의 본문만 있는 버전이에요 (index.html은 이걸로 만들어요).
